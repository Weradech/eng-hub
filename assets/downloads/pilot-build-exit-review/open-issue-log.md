For an actual DFx finding, include an image from the analysis plus source file,
revision, tool/view, location and explanation of what the image demonstrates.
Do not substitute a generic illustration for inspection evidence.

Keep observation, hypothesis and confirmed cause distinct. Record repeat failures
and reopen issues when the applicable process requires it. Preserve earlier history.
